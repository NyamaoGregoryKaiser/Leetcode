Min Stack (Two Stacks Approach)

Goal: Implement a stack with O(1) push, pop, top, and getMin.

Concept: Use two stacks. One (Main Stack) stores all values. The other (Min Stack) only stores minimums.

Example: Push sequence: 5, 2, 4, 1, 3

Initial State:
Main Stack: []
Min Stack:  []

1. Push 5:
   Main Stack: [5]
   Min Stack:  [5]   (5 is current min)

2. Push 2:
   Main Stack: [5, 2]
   Min Stack:  [5, 2]   (2 is new min, 2 <= 5)

3. Push 4:
   Main Stack: [5, 2, 4]
   Min Stack:  [5, 2]   (4 is not <= 2, so 2 remains min)

4. Push 1:
   Main Stack: [5, 2, 4, 1]
   Min Stack:  [5, 2, 1]   (1 is new min, 1 <= 2)

5. Push 3:
   Main Stack: [5, 2, 4, 1, 3]
   Min Stack:  [5, 2, 1]   (3 is not <= 1, so 1 remains min)

Current State:
Main Stack: [5, 2, 4, 1, 3]  (Top: 3)
Min Stack:  [5, 2, 1]       (Top: 1)

getMin() -> 1 (O(1))
top()    -> 3 (O(1))

6. Pop: (Value 3 is popped from Main Stack)
   Is 3 == Min Stack top (1)? No.
   Main Stack: [5, 2, 4, 1]
   Min Stack:  [5, 2, 1]

Current State:
Main Stack: [5, 2, 4, 1]  (Top: 1)
Min Stack:  [5, 2, 1]     (Top: 1)

getMin() -> 1
top()    -> 1

7. Pop: (Value 1 is popped from Main Stack)
   Is 1 == Min Stack top (1)? Yes. Pop from Min Stack too.
   Main Stack: [5, 2, 4]
   Min Stack:  [5, 2]

Current State:
Main Stack: [5, 2, 4]  (Top: 4)
Min Stack:  [5, 2]     (Top: 2)

getMin() -> 2
top()    -> 4

This demonstrates how `minStack.peek()` always gives the current minimum in O(1).
The crucial part is pushing to `minStack` if `val <= minStack.peek()`, which handles duplicates correctly.
