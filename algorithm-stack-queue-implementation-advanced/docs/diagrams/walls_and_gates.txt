Walls and Gates (Multi-Source BFS)

Goal: Fill empty rooms (INF) with distance to nearest gate (0). Walls are -1.

Concept: Start a BFS from *all* gates simultaneously. Each step outwards increases the distance by 1.
The first time an empty room is reached, it's the shortest path.

Example Grid:
INF  -1   0  INF
INF INF INF  -1
INF  -1 INF  -1
  0  -1 INF INF

Represent INF as a very large number (e.g., 2147483647 in int)

Initial Grid:
[ I, -1,  0,  I ]
[ I,  I,  I, -1 ]
[ I, -1,  I, -1 ]
[ 0, -1,  I,  I ]

Queue (stores [row, col]):
Initialize queue with all gates:
Queue: [[0,2], [3,0]]

Iteration 1 (Distance 0 cells processed):
- Dequeue [0,2] (Value 0)
  - Neighbors: [0,1](-1,wall), [0,3](INF), [1,2](INF)
  - [0,3] is INF: rooms[0,3] = rooms[0,2] + 1 = 0 + 1 = 1. Enqueue [0,3].
  - [1,2] is INF: rooms[1,2] = rooms[0,2] + 1 = 0 + 1 = 1. Enqueue [1,2].
  Grid:
  [ I, -1,  0,  1 ]
  [ I,  I,  1, -1 ]
  [ I, -1,  I, -1 ]
  [ 0, -1,  I,  I ]
  Queue: [[3,0], [0,3], [1,2]]

- Dequeue [3,0] (Value 0)
  - Neighbors: [2,0](INF), [3,1](-1,wall)
  - [2,0] is INF: rooms[2,0] = rooms[3,0] + 1 = 0 + 1 = 1. Enqueue [2,0].
  Grid:
  [ I, -1,  0,  1 ]
  [ I,  I,  1, -1 ]
  [ 1, -1,  I, -1 ]
  [ 0, -1,  I,  I ]
  Queue: [[0,3], [1,2], [2,0]]

Iteration 2 (Distance 1 cells processed):
- Dequeue [0,3] (Value 1)
  - Neighbors: [0,2](0,gate), [1,3](-1,wall)
  - No INF neighbors (or neighbors are already <= current path, so ignore).
  Queue: [[1,2], [2,0]]

- Dequeue [1,2] (Value 1)
  - Neighbors: [0,2](0,gate), [1,1](INF), [1,3](-1,wall), [2,2](INF)
  - [1,1] is INF: rooms[1,1] = rooms[1,2] + 1 = 1 + 1 = 2. Enqueue [1,1].
  - [2,2] is INF: rooms[2,2] = rooms[1,2] + 1 = 1 + 1 = 2. Enqueue [2,2].
  Grid:
  [ I, -1,  0,  1 ]
  [ I,  2,  1, -1 ]
  [ 1, -1,  2, -1 ]
  [ 0, -1,  I,  I ]
  Queue: [[2,0], [1,1], [2,2]]

- Dequeue [2,0] (Value 1)
  - Neighbors: [1,0](INF), [2,1](-1,wall), [3,0](0,gate)
  - [1,0] is INF: rooms[1,0] = rooms[2,0] + 1 = 1 + 1 = 2. Enqueue [1,0].
  Grid:
  [ I, -1,  0,  1 ]
  [ 2,  2,  1, -1 ]
  [ 1, -1,  2, -1 ]
  [ 0, -1,  I,  I ]
  Queue: [[1,1], [2,2], [1,0]]

Iteration 3 (Distance 2 cells processed):
- Dequeue [1,1] (Value 2)
  - Neighbors: [0,1](-1,wall), [1,0](2,visited), [1,2](1,visited), [2,1](-1,wall)
  - No unvisited INF neighbors.
  Queue: [[2,2], [1,0]]

- Dequeue [2,2] (Value 2)
  - Neighbors: [1,2](1,visited), [2,1](-1,wall), [2,3](-1,wall), [3,2](INF)
  - [3,2] is INF: rooms[3,2] = rooms[2,2] + 1 = 2 + 1 = 3. Enqueue [3,2].
  Grid:
  [ I, -1,  0,  1 ]
  [ 2,  2,  1, -1 ]
  [ 1, -1,  2, -1 ]
  [ 0, -1,  3,  I ]
  Queue: [[1,0], [3,2]]

- Dequeue [1,0] (Value 2)
  - Neighbors: [0,0](INF), [1,1](2,visited), [2,0](1,visited)
  - [0,0] is INF: rooms[0,0] = rooms[1,0] + 1 = 2 + 1 = 3. Enqueue [0,0].
  Grid:
  [ 3, -1,  0,  1 ]
  [ 2,  2,  1, -1 ]
  [ 1, -1,  2, -1 ]
  [ 0, -1,  3,  I ]
  Queue: [[3,2], [0,0]]

Iteration 4 (Distance 3 cells processed):
- Dequeue [3,2] (Value 3)
  - Neighbors: [2,2](2,visited), [3,1](-1,wall), [3,3](INF)
  - [3,3] is INF: rooms[3,3] = rooms[3,2] + 1 = 3 + 1 = 4. Enqueue [3,3].
  Grid:
  [ 3, -1,  0,  1 ]
  [ 2,  2,  1, -1 ]
  [ 1, -1,  2, -1 ]
  [ 0, -1,  3,  4 ]
  Queue: [[0,0], [3,3]]

- Dequeue [0,0] (Value 3)
  - Neighbors: [0,1](-1,wall), [1,0](2,visited)
  - No unvisited INF neighbors.
  Queue: [[3,3]]

Iteration 5 (Distance 4 cells processed):
- Dequeue [3,3] (Value 4)
  - Neighbors: [2,3](-1,wall), [3,2](3,visited)
  - No unvisited INF neighbors.
  Queue: []

Queue is empty. BFS finishes.

Final Grid:
[  3, -1,  0,  1 ]
[  2,  2,  1, -1 ]
[  1, -1,  2, -1 ]
[  0, -1,  3,  4 ]
